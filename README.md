# Restaurant Orders Dashboard Report.

## Project Overview.

The Restaurant Orders Dashboard is an interactive Power BI report developed to analyze restaurant sales performance using order-level transactional data. The dashboard provides management with insights into revenue, sales trends, product performance, pricing, and customer ordering behavior.

The dashboard enables users to filter data by Food Category and Month, allowing quick exploration of sales performance across different segments.


## Objective.

The primary objective of this dashboard is to answer the following business questions:
- How much revenue did the restaurant generate.
- Which menu items generate the highest sales.
- Which categories perform the best.
- How do sales change over time.
- What is the average customer spending.
- Which products have the highest order value.

## KPI Analysis
**1.** Total Orders:
   This KPI represents the total number of customer orders placed during the selected period.  
**2.** Total Revenue
   Represents the total revenue generated from all completed orders.  
**3.** Items Sold
   Represents the total quantity of menu items sold.   
**4.** Average Item Price
   Shows the average selling price of menu items.  
**5.** Average Order Value:
   Represents the average amount spent per customer order. explain this in simple words.
